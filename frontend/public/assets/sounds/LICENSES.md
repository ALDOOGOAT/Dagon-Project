# Sound Assets

## Kenney Interface Sounds

- Source: https://kenney.nl/assets/interface-sounds
- Download used: `kenney_interface-sounds.zip`
- License: Creative Commons CC0 1.0 Universal, included in `License.txt`
- Files copied into this project:
  - `open_001.ogg`
  - `select_001.ogg`
  - `confirmation_001.ogg`
  - `question_001.ogg`
  - `error_001.ogg`
  - `tick_001.ogg`
  - `switch_001.ogg`

These files are used as optional UI/cinematic sound cues. `SoundEngine` keeps Web Audio synthesis as fallback if local audio playback fails.

Current use in Dagon:
- Dashboard buttons and feedback effects.
- Module cinematics and onboarding tutorial cues.
- Global mute support through `frontend/src/lib/SoundEngine.js`.

Voice narration is generated by the browser Web Speech API; it does not add bundled third-party audio files.
